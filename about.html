About This Site

sharing simple tools I find useful

What is this?

This is a collection of simple, focused web tools that solve specific problems. Each tool is designed to be lightweight, easy to use, and accessible directly from your browser without any installation, signup or (as much as possible) internet required.

Many of them are slop-coded, but I review the code myself before uploading it. No data leaves your phone. There's no tracking of any kind. Useful, local, tools.

Open Source

All tools on this site are open source (MIT license) and freely available. Author assumes no liability and all software is provided as-is.
